개인정보 처리방침

시행일 2026-08-15 · AI 레이더(운영: 애플시드)

이메일 주소는 로그인 과정에서 저장하지 않습니다. 구글 로그인은 이메일을 함께 알려주지만, 저희는 그 값을 어느 문서에도 적지 않습니다. 이메일을 저장하는 곳은 아래 "마감 알림" 하나뿐이고, 그건 직접 적어 주셨을 때만입니다.

1. 무엇을 저장하나요

서비스가 실제로 저장하는 값은 아래가 전부입니다.

구분저장하는 값언제
프로필 계정 식별자(uid), 닉네임, 프로필 주소(슬러그), 한 줄 소개, 대표 링크, 프로필 사진 주소, 만든 시각 구글 로그인을 하면 자동으로 만들어집니다. 닉네임과 사진은 구글 계정의 이름·사진을 기본값으로 씁니다.
게시판 글·답글 계정 식별자, 표시 이름, 프로필 사진 주소, 본문, 태그, 좋아요·답글 수, 작성·수정 시각 글이나 답글을 남길 때
작품 계정 식별자, 제목, 영상 주소와 영상 ID, 관련 공모전 표시, 좋아요 수, 올린 시각 작품을 올릴 때
좋아요계정 식별자, 누른 시각좋아요를 누를 때
마감 알림이메일 주소, 신청 시각, 신청한 화면메인 화면에서 직접 적어 신청했을 때만

2. 저장하지 않는 것

  • 로그인 계정의 이메일 주소(마감 알림에 직접 적으신 경우는 제외)
  • 비밀번호 — 비밀번호를 받지 않습니다. 인증은 구글이 대신합니다.
  • 전화번호, 주소, 생년월일, 결제 정보
  • 별도의 광고·추적 도구를 넣지 않았습니다.

3. 왜 저장하나요

  • 누가 쓴 글·작품인지 표시하고, 본인만 고치고 지울 수 있게 하려고
  • 공개 프로필 주소(/u/닉네임)를 만들어 드리려고
  • 마감 알림을 신청하신 분께 메일을 보내려고

4. 공개되는 범위

프로필, 게시판 글, 작품, 좋아요 수는 로그인하지 않은 사람도 볼 수 있습니다. 공개 게시판이기 때문입니다. 남기기 전에 공개해도 괜찮은 내용인지 확인해 주세요. 마감 알림 이메일 목록은 화면에서 누구도 읽을 수 없게 막아 두었습니다.

5. 맡기는 곳

  • Google (Firebase 인증·Cloud Firestore) — 로그인과 데이터 보관. 데이터는 서울 리전에 있습니다.
  • GitHub Pages — 화면 파일 전송
  • Google Apps Script — 공모전·지원사업 등 목록 데이터 제공
  • i.ytimg.com, cdn.jsdelivr.net — 유튜브 썸네일과 글꼴 파일

이들 서비스는 접속 과정에서 IP 주소 등 접속 기록을 자체적으로 남길 수 있습니다.

6. 얼마나 보관하나요

올려 주신 글·작품·프로필은 직접 지우실 때까지 보관합니다. 계정과 남긴 기록 전부를 지우고 싶으시면 아래 메일로 알려 주세요. 확인 후 지워 드립니다. (지금은 화면 안에 "계정 삭제" 버튼이 없어 메일로 처리합니다.)
